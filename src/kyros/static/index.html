Indicator analysis

Domain Intelligence

Validación local del formato de dominios.
Introduce un dominio sin URL ni ruta.
Las consultas DNS solo se realizan si autorizas la casilla. Se consultan A, AAAA, MX, TXT y _dmarc; no se consulta reputación ni se valida DKIM.
Email intelligence

Email Intelligence

Validación local de direcciones sin divulgación externa.
Introduce una dirección para validar su formato.
Esta comprobación solo valida sintaxis y normaliza el dominio. No confirma que el buzón exista ni consulta DNS, brechas o reputación. La dirección no se envía a servicios externos.
Static file triage

File Intelligence

Identificación por firma y estructura, hashes y revisión estática de documentos Office.
Selecciona un archivo para iniciar el triaje.
El archivo se procesa en memoria y no se ejecuta ni se envía a terceros. En documentos Office se valida la estructura Open XML y se indican macros, fórmulas y enlaces externos cuando se detectan. Estos elementos no constituyen por sí solos un veredicto de malware. YARA es opcional; ClamAV y sandbox no están integrados. Evita subir muestras confidenciales.
